Installing

  1. Open the downloaded Stock-Compass-Setup file.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. This appears because Stock Compass is a new independent app that isn't code-signed yet.
  3. Follow the installer. It adds Stock Compass to your Start menu and desktop.
  4. Open Stock Compass and follow the short setup.
  1. Open the downloaded .dmg file and drag Stock Compass into your Applications folder.
  2. The first time, right-click (or Control-click) Stock Compass in Applications and choose Open, then Open again. macOS asks this because the app isn't notarized by Apple yet.
  3. If macOS still blocks it, go to System Settings → Privacy & Security and click Open Anyway.
  4. If it says the app "is damaged", open Terminal and run xattr -cr "/Applications/Stock Compass.app", then open it again.

Stock Compass is built automatically by GitHub from its public source code. It has no server: it never collects your data, and it only connects to the market data, AI and broker services you set up.
